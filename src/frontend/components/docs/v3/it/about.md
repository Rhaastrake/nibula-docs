## Informazioni su Eleventy (11ty) {id="about-eleventy"}

**Eleventy è il motore sottostante.** Prende i tuoi template e i tuoi dati e
li trasforma in semplici file HTML, una volta sola, quando fai la build — ed è
per questo che il risultato è solo una cartella che puoi caricare ovunque.

**Nibula è uno strato sopra, non un sostituto.** Eleventy ti dà la build;
Nibula aggiunge la struttura delle cartelle, la pipeline di **SCSS** e
**JavaScript**, l'assistente per le pagine, i file **SEO** e le configurazioni
dei server. Tutto ciò che può fare Eleventy, può farlo anche il tuo progetto —
comprese le parti che Nibula non configura per te.

`.eleventy.js` si trova nella root del progetto, ed è lo stesso file di
configurazione che troveresti in qualsiasi progetto Eleventy. Quando ti serve
qualcosa oltre a ciò che Nibula collega — un nuovo filtro, una collection, una
cartella di output diversa — la
[documentazione di Eleventy](https://www.11ty.dev/docs/) vale direttamente,
senza bisogno di adattamenti.

## Supporta Nibula {id="support-nibula"}

Grazie per aver provato **Nibula**.

È un progetto di una sola persona, quindi ogni feedback conta più di quanto pensi: se qualcosa si rompe, se la documentazione non è chiara o se manca una funzionalità, apri una [issue](https://github.com/Rhaastrake/Nibula/issues).

Se **Nibula** ti è stato utile, lasciare una stella sul [repository](https://github.com/Rhaastrake/Nibula) è il modo più semplice per aiutare altre persone a trovarlo.

Puoi anche supportare il progetto offrendomi un caffè su [PayPal](https://paypal.me/rhaastrake)
